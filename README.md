# 降雨数据算法与流域平均雨量计算示例

## 评分标准

本项目作为教学项目，采用以下评分体系评估学生的完成情况：

| 等级 | 分数区间 | 完成标准 |
|------|----------|----------|
| **A** | 90-100分 | 能跑完**所有流域**，串行处理**40年**的数据。<br>• 100分：限时**一周**完成<br>• 90-99分：根据完成时间和流域数量评定 |
| **B** | 80-89分 | 能跑完**大部分流域**（50%以上），处理**长时间序列**数据（如20年以上）。<br>具体分数根据流域覆盖率和时间跨度评定 |
| **C** | 70-79分 | 能跑完**部分流域**（25-50%），处理**较长时间序列**数据（如10-20年）。<br>具体分数根据流域数量和年份数评定 |
| **D** | 60-69分 | 能跑完**一个流域多年**数据（如1-10年），参考示例教程完成要求。<br>具体分数根据完成情况评定 |
| **F** | <60分 | 未能达到及格标准 |

**及格标准（60分）**: 跑完**一个流域一年**的数据，不限制运算时间，但每个人不可重复流域，一经发现重复两者均记为0分


## 概述

降雨是水文循环的重要组成部分，也是水文建模的关键输入数据。准确获取和处理降雨数据对于水文分析、洪水预报和水资源管理至关重要。

本项目提供了从获取公开降雨数据到高级算法扩展的完整流程，涵盖了现代降雨数据处理的理论基础、算法实现、性能优化等各个方面。

## 教程结构

### 第一部分：数据获取 (`1_data_acquisition.ipynb`)
学习如何从公开数据源获取降雨数据：

**主要数据源：**
- **GFS (Global Forecast System)**: 美国国家气象局全球数值天气预报模式
- **MSWEP (Multi-Source Weighted-Ensemble Precipitation)**: 多源加权集合降雨再分析数据

**核心内容：**
- 数据访问接口和API使用
- 数据格式解析和预处理
- 数据质量初步检查
- 本地存储和管理

### 第二部分：算法实现与性能对比 (`2_data_processing.ipynb`)
使用面积占比的流域平均雨量计算算法

**性能评估体系：**
- 计算效率对比(耗时)
- 精度评估


### 第三部分：算法扩展与优化 (`3_extensions.ipynb`)
探索现代计算技术和高级算法：

**并行计算优化：**
1. **多进程并行**
   - ProcessPoolExecutor实现
   - 负载均衡和任务分配
   - 2-8倍性能提升

2. **Numba JIT优化**
   - 即时编译技术
   - CUDA GPU加速支持
   - 10-50倍计算加速

3. **Dask分布式计算**
   - 延迟计算和任务图
   - 内存高效的大数据处理
   - 支持TB级数据集
