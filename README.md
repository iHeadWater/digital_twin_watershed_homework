# 降雨数据算法与流域平均雨量计算示例

## 评分标准

本项目作为《数字孪生流域》课程作业，采用以下评分体系评估学生的完成情况：

| 等级 | 分数区间 | 完成标准 |
|------|----------|----------|
| **A** | 90-100分 | 能跑完**所有流域**，处理**40年**的降水数据。<br>• 100分：限时**两周**完成<br>• 90-99分：根据完成时间和流域数量评定 |
| **B** | 80-89分 | 能跑完**大部分流域**（50%以上），处理**较长时间序列**数据（如10年以上）。<br>具体分数根据流域覆盖率和时间跨度评定 |
| **C** | 70-79分 | 能跑完**部分流域**（25-50%），处理**多年时间序列**数据（如1-10年）。<br>具体分数根据流域数量和年份数评定 |
| **D** | 60-69分 | 能跑完**一个流域多年**数据（如1-10年），参考示例教程完成要求。<br>具体分数根据完成情况评定 |
| **F** | <60分 | 未能达到及格标准 |

**及格标准（60分）**: 跑完**一个流域一年**的数据，不限制运算时间，***但每个人随机挑选流域，不能完全重复随机种子和重复流域号，一经发现重复，会检查两人代码，完全重复，本次作业记为0分***


## 概述

降雨是水文循环的重要组成部分，也是水文建模的关键输入数据。准确获取和处理降雨数据对于水文分析、洪水预报和水资源管理至关重要。

本项目提供了从获取公开降雨数据计算面平均降雨的完整流程，本教程可使用**jupyterhub服务器**，集成了conda环境，简单易实现

但由于部分数据需要科学上网下载，更推荐使用**本地运行**

## 教程结构

### 第一部分：数据获取 (`1_data_acquisition.ipynb`)
学习如何从公开数据源获取降雨数据：

**主要数据源：**
- **GFS (Global Forecast System)**: 美国国家气象局全球数值天气预报模式
- **MSWEP (Multi-Source Weighted-Ensemble Precipitation)**: 多源加权集合降雨再分析数据

**任选一个数据源完成即可!! 时间尺度为日尺度或者3h尺度** 


### 第二部分：算法实现与性能对比 (`2_data_processing.ipynb`)
使用面积占比的流域平均雨量计算算法，并得出用时长短


### 第三部分：算法扩展与优化 (`3_extensions.ipynb`)
需要自行探索如何进行**并行计算优化**，让计算时间更短
